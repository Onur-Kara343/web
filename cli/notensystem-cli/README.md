# Notensystem CLI

Ein interaktives CLI-Tool zur Berechnung von Punkten und Noten in einem 15-Punkte-System.

## Installation

1. `cd notensystem-cli`
2. `npm install`

## Nutzung

`node nsystem.js`

## Ablauf

- Frage nach maximalen Punkten der Arbeit
- Frage nach erreichten Punkten
- Berechnet die Punkte auf einer Skala von 0 bis 15
- Gibt eine Einordnung wie `sehr gut`, `gut`, `befriedigend` usw. aus
