# JPG Wandler CLI

Konvertiert Bilder im Ordner `images/` in das JPG-Format und speichert sie im Ordner `convert/`.

## Installation

1. `cd jpg-wandler-cli`
2. `npm install`

## Nutzung

`npm start`

## Details

- Eingabeordner: `images/`
- Ausgabeordner: `convert/`
- Unterstützte Formate: `.jpg`, `.jpeg`, `.png`, `.webp`, `.tiff`, `.gif`

## Hinweise

Der Ordner `convert/` wird automatisch erstellt, falls er noch nicht existiert.
