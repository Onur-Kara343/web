# Ordnerstruktur CLI

Ein CLI-Tool zum Erstellen einer Basisprojektstruktur mit Beispieldateien.

## Installation

1. `cd ordnerstruktur-cli`
2. `npm install`

## Nutzung

`node index.js <Projektname>`

Beispiel:

`node index.js meinProjekt`

Anschließend nach dem Zielpfad fragen und dort wird die neue Projektstruktur angelegt.

## Ergebnis

Erstellt einen neuen Ordner mit folgenden Strukturen und Beispiel-Dateien:

- `db`
- `middleware`
- `models`
- `routes`
- `public/js`
- `server.js`
- `package.json`
- `.env`
