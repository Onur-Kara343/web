# Password Generator CLI

Ein interaktives CLI-Tool zur Erzeugung sicherer Passwörter.

## Installation

1. `cd password-cli`
2. `npm install`

## Nutzung

`node password.js`

Anschließend die gewünschte Passwortlänge eingeben (8 bis 32).

## Hinweise

- Es werden Großbuchstaben, Kleinbuchstaben, Zahlen und Sonderzeichen verwendet.
- Ungültige Eingaben werden abgefangen.
