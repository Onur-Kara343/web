# Datei-Größe CLI

Ein einfaches CLI-Tool, das die Größe einer Datei in Bytes berechnet.

## Installation

1. `cd datei-groesse-cli`
2. `npm install`

## Nutzung

`node groesse.js`

Anschließend den vollständigen Pfad zur Datei eingeben.

## Funktionsweise

- Liest eine Datei vom angegebenen Pfad
- Berechnet die Größe in Bytes
- Gibt das Ergebnis in der Konsole aus
