# MorseCode CLI

Ein interaktives CLI-Tool zur Umwandlung von Text in Morsecode und zurück.

## Installation

1. `cd morseCode-cli`
2. `npm install`

## Nutzung

`node mc.js`

## Ablauf

1. Wähle `1` für Text → Morse
2. Wähle `2` für Morse → Text
3. Gib den gewünschten Text oder Morsecode ein

## Hinweise

- Wörter werden im Morsecode durch `/` getrennt.
- Ungültige Zeichen werden als `?` dargestellt.
