# JSON Formatter CLI

Ein CLI-Tool zum Formatieren von JSON-Text.

## Installation

1. `cd json-formatter-cli`
2. `npm install`

## Nutzung

`node jsF.js`

Anschließend JSON-Daten in der Konsole eingeben.

## Beispiel

Gib folgendes ein:

`{"name":"Max","age":25}`

Das Tool gibt formatiertes JSON mit Einrückungen zurück.
