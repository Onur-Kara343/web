# 📘 Exam Simulator SaaS

An AI-powered exam generation platform that creates realistic multiple-choice exams from uploaded PDFs and text scripts with automatic grading and feedback.

## Features

- 📄 **Upload PDF & TXT files** - Extract text content automatically
- ✍️ **Manual script input** - Add study notes directly
- 🧠 **Intelligent question generation** - Creates relevant MCQs based on content
- ✅ **Auto-grading system** - Instant scoring with detailed feedback
- 📊 **Performance analytics** - Track strengths and weaknesses
- 🎨 **Modern responsive UI** - Works on desktop and mobile
