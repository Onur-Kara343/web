# Logo Playground

Logo Playground ist ein interaktiver Logo-Editor auf Canvas-Basis. Ein Design kann direkt im Browser zusammengestellt und als PNG exportiert werden.

## Funktionen

- Rechteck, Kreis, Dreieck, Stern, Linie und Text einfuegen
- Farbe, Groesse, Rotation, Position und Fuellung bearbeiten
- Elemente auswaehlen und als Ebenen verwalten
- Ebenen nach vorne oder hinten verschieben
- Elemente zentrieren oder loeschen
- Das fertige Logo als PNG exportieren
- Das gesamte Design zuruecksetzen

## Technik

- HTML, CSS und Vanilla JavaScript
- HTML-Canvas
- Keine Serverkomponente und keine Persistenz

## Start

Keine Installation erforderlich. Oeffne [index.html](index.html) direkt im Browser:

```text
logo-playground/index.html
```

Es gibt kein Backend, keine Datenbank und keine Umgebungsvariablen.
